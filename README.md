# SopramLAMG
Welcome to The Sopram for the Stankler Folly Formula!
**Now updated for LAMG3!**

This Sopram will calculate the outcome of any battle, given the army statistics, for LAMG.

To use it, follow the instructions, and record the result.
You may continue with multiple battles at the end.

The program automatically saves the results of battles you put in, so you dont need to worry if you didn't record it then and there.

As of the latest version, the Sopram now supports prediction of an enemy's attack/defence tech value! Input number of battles as data points and the software will determine the average value for you. Since the randomness is uniform, it will be incredibly accurate the more values you can use!

This program has AI-Assisted components, primarily consisting of the newly added Prediction formula and function. Derivations were done mostly by me, and i used Claude to clean it all up into a readable manner.
